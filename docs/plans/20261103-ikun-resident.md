# IKUN 居民与配置核对

- 复用示例的 `terry-skin.png` 和引擎人物模型，保持玩家皮肤、跨站访客皮肤不变。
- 在 IKUN 四米高的房间内布置床，显式沿楼梯进出，陆地使用现有寻路，水上活动使用避障水路。
- 白天轮换散步、海滩坐卧、钓鱼、摩托艇活动，夜晚中断活动、下艇、游回岸边并步行回家睡觉。
- 座位和摩托艇有占用检查，不抢玩家正在使用的资源；距离接近且无遮挡时招手，设置离开距离和冷却时间。
- 名牌使用 DOM，钓竿合并绘制，床复用已有家具批次，不加实时灯光。
- 修复邮箱、联系方式和双语介绍的填写位置；以 `homecraft.json` 的站名为准，保留尚未提供的 Logo、玩家皮肤和天气城市待确认。
- 遵守用户暂不运行测试的要求，只同步回归用例，后续可运行 `npm run check:resident` 和 `npm run check`。
