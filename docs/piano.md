# 钢琴角与背景音乐

钢琴位于工作台家东北角。`world/layout.js` 中的 `PIANO` 同时控制模型位置与交互站位；家具、地毯、灯具和植物在 `world/gonglu-furnish.js` 中构建。

## 背景音乐

- 每次打开或刷新网站，背景音乐默认关闭，不读取或保存自动开启偏好。
- 在钢琴面板选择曲谱，勾选“背景音乐 · 自动循环”，由这次手动操作启动声音。
- 开启后，关闭钢琴面板、切换卡片或走到岛上其他位置，音乐继续播放；曲目结束后从头循环。
- 世界画面右上方出现小播放器，可以暂停、继续或关闭音乐；重新打开钢琴面板可以换曲和调整音量。
- 面板中的“停止”、取消背景音乐或进入练习模式，都会停止背景音乐。
- 不勾选背景音乐时，普通播放只在钢琴面板中生效，关闭面板即停止。
- 音量默认 25%，与世界环境音效开关独立。关闭网站后停止播放；浏览器休眠、锁屏或后台节流可能中断声音，不保证系统后台持续播放。

播放器是 `engine/ui/piano-music.js` 中独立于面板的会话级服务，不在世界逐帧更新中分配音频对象。合成器按音符调度，不加载外部音频文件。

## 检查

先运行 `python tools/serve.py`，然后运行 `npm run check:piano` 和 `npm run check`。前者覆盖简谱、定位标记、移动端排版，以及背景音乐默认关闭、循环、关闭面板后的持续播放和恢复。
