## 乐魂:站立 bug 修复 + 内饰方案(一楼健身房 / 二楼休闲角,樱花粉主题)

### 一、站立 bug 根因与修复(已勘察确认)
- **根因**:乐魂(z 36~52)整个落在"环岛海洋"判定 `inPool` 内,导航网格把全屋格子标成水池/阻挡,`floorAt` 的 12 米地板没生效——所以进去站不住,靠近还会触发跳水。
- 修复(引擎,沿用此前授权):
  1. `engine/world/nav.js` 建网格时,有真实地板的格子不再按水池处理:`if (inPool(x, z) && !floorAt(x, z))`。屋下海水游泳不受影响。
  2. `world/layout.js` floorAt:乐魂地板范围补上漏掉的西侧一列(x≥2),并给南门门槛一行(wz 50)补 12,门口不再"断层"。
  3. 顺手修玻璃幕墙重复渲染:`mapLeHun` 里 `stained_glass_pane` 不再入网格(只留薄片形状),省一批重叠面。
- 地板本身是好的(白色混凝土,顶面正好 y=12);苔藓花坛(+1m)、东侧樱花木柱、南行树叶会作为障碍物保留。

### 二、一楼健身房(地面大厅 y=12,约 15×14m)
参照示例家的训练区做法(全部 BoxBatch 静态件,进现有 model 批次,零新增 draw call):
- **橡胶训练区** 8×5m 深灰橡胶地垫,边缘一圈樱花粉收边条,放在大厅中东部。
- **器材**(示例家同款造型,粉垫配色):引体向上架、哑铃架+三组哑铃、龙门架(双配重)、跑步机、动感单车、仰卧板。
- **瑜伽角**(西北,靠苔藓花园):两块粉色瑜伽垫 + 盆栽 + 小置物架。
- **水吧/毛巾架** 贴南墙东侧。
- 西墙楼梯、苔藓花坛、东条篝火角、南门通道全部留空(≥1.2m)。

### 三、二楼休闲角(原版阁楼夹层,表面 y≈19.5~20.5,约 4×4m)
- 樱花木矮柜 + 电视(挂南墙,接 `surfaces.tvScreen`)+ 游戏机。
- 两只懒人沙发(樱花粉 + 米白)、矮茶几、圆形长绒地毯。
- 平台边缘一圈暖光灯串(bake)+ 盆栽,保留原版朝西的小门和玻璃带采光。
- 樱花粉主题贯穿:粉垫、粉地毯、粉灯串,配樱花木与白色。
